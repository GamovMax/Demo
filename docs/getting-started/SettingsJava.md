# Settings.java

Для локальной работы нужно создать и заполнить в папке `Demo\src\main\java\constants` файл **Settings.java**,  
где `SettingsExample.java` – шаблон такого файла.

| Параметр               | Описание                                  |
|------------------------|-------------------------------------------|
| `LOGIN`                | Логин для авторизации                     |
| `PASSWORD`             | Пароль для авторизации                    |
| `URL_CLIENT`           | URL главной клиентской страницы сервиса   |
| `URL_ADMIN`            | URL админки сервиса                       |
| `URL_LOGIN`            | URL страницы с формой авторизации         |
| `URL_TRANSLATE_YANDEX` | URL для 'Яндекс Переводчика'              |
| `IMPLICIT_WAIT`        | Длительность неявного ожидания в секундах |
| `EXPLICIT_WAIT`        | Длительность явного ожидания в секундах   |
