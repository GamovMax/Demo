# Как выставлять версии для изменений в проекте?

Система обновления версий похожа на `Semantic Versioning`. Обновлять версии в **README.md**.
- **Major**
	- Принципиально переработана структура автотестов
	- Был осуществлен переход на другой фреймворк/язык/паттерн проектирования
- **Minor** (Feat)
	- Новые автотесты
	- Изменены текущие автотесты
	- Была поправлена/улучшена логика
- **Patch** (Refactoring, Fix)
	- Устранение флаки-тестов, исправление ошибок в коде, маленькие правки, рефакторинг и т.п.
