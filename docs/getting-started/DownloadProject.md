# Загрузка проекта

Проект выгружается из **git-репозитория**.

Это можно сделать через **IntelliJ IDEA**, так что запускаем его:
1. Нажимаем **Get from VCS**
2. В качестве **URL** указываем ссылку на проект (https://tfs.example.ru/tfs/exampletc1/DEP_PMO/_git/r_autotests)
3. Указываем расположение проекта
4. Нажимаем **Clone**
5. Дожидаемся окончания загрузки и прочих процессов в футбаре IntelliJ IDEA
