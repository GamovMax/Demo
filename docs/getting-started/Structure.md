# Структура проекта

---

- **docs** – документация автотестового проекта.
- **src/main/java** – база автотестов 
  - **common** – конфигурационная папка
  - **constants** – папка, содержащая файлы с константами
    - **SettingsExample.java** – файл с переменными окружения
      - для локальной разработки создается файл **Settings.java**, который уже и заполняется нужными значениями
  - **pages** – папки с описанием страниц Page, основанных на BasePage
- **src/test/java** – файлы с тестами
  - **tests/base/BaseTest.java** – базовый тестовый класс, от него наследуются все остальные тесты
  - **tests/ui** – UI-автотесты
